## 📖 Giới thiệu

**TechStore** là website bán hàng điện tử được xây dựng nhằm vận dụng kiến thức Java Web vào một ứng dụng thực tế. Website hỗ trợ khách hàng tìm kiếm sản phẩm, quản lý giỏ hàng và đặt hàng; đồng thời cung cấp các chức năng quản lý dành cho quản trị viên.

## ✨ Chức năng chính

- **Khách hàng:** Đăng ký, đăng nhập, tìm kiếm và xem chi tiết sản phẩm, quản lý giỏ hàng, đặt hàng COD và xem lịch sử đơn hàng.
- **Quản trị viên:** Quản lý sản phẩm, tài khoản khách hàng, đơn hàng, tồn kho và thống kê bán hàng.

## 🧰 Công nghệ sử dụng

| Công nghệ | Vai trò |
|---|---|
| Java Servlet, JSP | Xử lý yêu cầu và hiển thị giao diện |
| JDBC | Kết nối cơ sở dữ liệu |
| Microsoft SQL Server | Lưu trữ dữ liệu |
| Apache Tomcat | Chạy ứng dụng web |
| HTML, CSS, JavaScript | Xây dựng giao diện |

## 🎯 Mục tiêu

Xây dựng website bán hàng có kết nối cơ sở dữ liệu, thực hành các chức năng quản lý cơ bản và củng cố kiến thức phát triển ứng dụng web bằng Java.
